** Zeige Dashboard **

Die Startansicht der App ist das Dashboard. Hier gibt es einen Überblick, über die aktuelle Finanzlage.

# Rollen 

* System, die App
* Anwender

# Ablauf

* Die Appliakation startet

* Das System startet die Ansicht Dashboard und zeigt darin eine Tabelle aller Konten vom Typ "Bestand" mit den Salden unter der Tabelle das Vermögen: die Summe aller Salden.

* Der Saldo eines Kontos ergibt sich aus der Summe der Beträge von den Buchungspositionen, die zum Konto gehören.

# Ablauf Variante

1. Der Anwender klickt in der Navagationsleise auf den ersten Eintrag "Dasboard". 
2. Das System zeig das Dashboard an, wie es im Ablauf beschrieben ist.
